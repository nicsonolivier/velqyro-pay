# VELQYRO PAY

MVP do checkout e painel de pagamentos VELQYRO PAY.

## Stack inicial

- React
- TypeScript
- Vite
- Lucide Icons

## Design System

- Roxo principal: `#7C3AED`
- Roxo vibrante: `#A855F7`
- Ciano: `#22D3EE`
- Fundo: `#09090F`
- Painéis: `#12121A`
- Bordas: `#27272F`

## Escopo V1

1. Cadastro / Login
2. Dashboard
3. Produtos
4. Checkout Builder
5. PIX / Cartão via PSP
6. Vendas
7. Clientes
8. Financeiro
9. Configurações
10. API / Webhooks básicos

> Os dados atuais do dashboard são demonstrativos. A próxima etapa é autenticação, persistência e backend.
